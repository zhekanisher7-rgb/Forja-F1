# Forja F1 2026 — Фаза 1+

Неофициальный фан-симулятор / трибьют Formula 1 сезона 2026.  
**Не связан** с Formula 1®, FIA, Liberty Media или командами. Лицензий нет — только стилизация.

Сделано для Melgy.

## Запуск

```bash
cd /workspace/f1-2026
npm install
npm run dev
```

Откройте URL из терминала (обычно `http://127.0.0.1:5173`).

Сборка:

```bash
npm run build
npm run preview   # опционально
```

Только веб (Vite + Three.js). Нативных сборок Win/mac нет.

## FPS-стратегия (цель ~60 на среднем ноутбуке)

Профили в **Настройки → Графика** (сохраняются в `localStorage`):

| Профиль | pixelRatio | Тени | Декор | Туман | AI Hz | Цель |
|---------|------------|------|-------|-------|-------|------|
| **Ультра-низкое** | ≤1 | OFF | минимум | короткий | 20 | спасательный круг |
| **Низкое** | ≤1 | OFF | мало | короткий | 24 | слабый iGPU |
| **Среднее** (default) | ≤1 | OFF | средний InstancedMesh | средний | 30 | **50–60 FPS** |
| **Высокое** | ≤1.25 | ON (1024, малый frustum) | больше | дальше | 40 | качество |

### Как проверить FPS
1. Меню → **Настройки** → **Счётчик FPS → Вкл (HUD)** → Сохранить
2. Запустить быструю гонку
3. В левом верхнем углу HUD: `NN FPS` (обновление ~2 раза/с)
4. Если &lt;50 на Среднем → переключить на **Низкое** или **Ультра-низкое**

### Что срезано ради FPS
- Shadows **выкл.** на Ultra/Low/Medium; High — маленькая shadow-карта
- `InstancedMesh` для зданий / деревьев / фонарей (единицы draw call вместо сотен)
- Декор **только** с внешней стороны асфальта+барьеров+margin (AABB vs ribbon)
- Lambert/Basic материалы на Medium и ниже; вода — Basic
- Разметка трассы — один merged BufferGeometry
- Нет tunnel PointLight; AI throttled
- Frustum culling ON; короткий fog

## Что улучшено в этой итерации

### Нет сине-белых кубов на асфальте
Убраны клумбы-боксы и синие спонсорские панели; Tecpro — только красно-белые soft-wall’ы (+ верхняя кромка). Декор дальше от ленты с доп. clearance.

### Машины F1 2026 (procedural)
Узкий нос, undercut sidepods, multi-element крылья, halo со стойками, колёса с диском/спицами, diffuser vanes. Сглаженные Standard-материалы + env reflections — без тяжёлых GLTF.

### Графика Medium ~60 FPS
Асфальт 512² с износом/маслом, env cubemap 128² с солнцем, ярче дневной свет, anisotropy 4, чуть больше scenery при том же pixelRatio 1 / без теней.

### Античит кругов
Круг засчитывается только при **прямом** пересечении S/F и после ≥**80%** длины трассы с прошлого круга. Обратная езда / дрожание у шва не удваивает круги; после финишной черты нужно выехать из зоны S/F (~40 м), чтобы снова «вооружить» детектор.

### Noghes / S/F без пересечений текстур
Сглаженный Noghes, terrain утоплен под асфальт, кербы/плечи/soft-edge **пропускают** ~20 м у шва петли — путь чистый, без z-fight лент.

### Барьеры Tecpro + спонсорские борды
Красно-белые soft-wall’ы (Tecpro-like) + брендированные панели **FORJA / TEC / HYDRO / NEXUS / …** (вымышленные имена, InstancedMesh).

### Живее пейзаж (с тирами качества)
Разнообразный грунт, скалы, клумбы, больше холмов/зданий и лодок на Medium+ — без ломки цели ~60 FPS на **Среднем**.

### Шире трасса Монако
Полуширина / `width` увеличены ×**4.0** (играбельная уличная ширина ~28–48 м, ~2× прежних ×2.05). Барьеры, кербы, стены и физическая проекция (`projectOnTrack` / halfW) берут ту же ширину — без рассинхрона.

### Нет серых плит на асфальте
Причал/apron гавани больше не режет Tabac (перенесены внутрь петли + `boxClearsRibbon`). Гравий и лодки только вне ленты. S/F — тонкий декал, не толстый бокс.

### Оверпассы без телепорта
`projectOnTrack(..., preferredS, preferredY)` штрафует чужую палубу и отказывает в прыжке >~2 м (кроме рампы). Под Swimming Pool / Beau Rivage машина остаётся на нижнем ярусе.

### Руль и сглаживание
A = влево, D = вправо. Аркадный отклик: быстрый lerp руля/газа, yaw-lerp чувствительнее, но без дёрганья на широкой ленте.

### Нет столбов посреди асфальта
Опоры эстакад/оверпассов ставятся **только вне** всех лент трассы (асфальт + margin). На X-пересечениях (Swimming Pool / Beau Rivage) боковой offset больше не падает на нижний центрлайн — столб либо выталкивается, либо пропускается. Нижние «балки»-deck по центрлайну убраны.

### Шов старт/финиш / Noghes
Anthony Noghes → S/F: непрерывный правый поворот без складки ленты (убран backtrack 70→50/−55). Касательная на стыке ≈ +Z. Закрытие петли чистит дубликаты; полоса S/F приподнята + polygonOffset.

### Ускорение
Меньшая масса (~620) и выше пиковая мощность (~980 кВт) — быстрее разгон.

### Столкновения машин
Круговые hitbox’ы игрок↔AI и AI↔AI: разделение, замедление/отскок при контакте, лёгкий урон — без ghosting.


### Здания не на трассе
Размещение вдоль **нормалей к краю** ленты. Любой проп, чья AABB пересекает асфальт+барьер+margin, **выталкивается** наружу или отбрасывается. Никакого random около центрлайна.

### ~60 FPS
См. таблицу профилей выше. Default = Medium без теней, pixelRatio 1.

### Реализм без убийства FPS
- Улучшенный procedural asphalt / kerb / фасады с окнами (canvas texture)
- Sky gradient + soft clouds (SceneSetup)
- Простая вода, инстанс-здания с окнами, дешёвые night-emissive на фонарях
- Убраны лишние лодки / point lights / клиппящий декор у барьеров

### Ранее
- Overpass underside decks только на реальных XZ-пересечениях
- 4 AI, HUD позиция, F1-силуэт машины
