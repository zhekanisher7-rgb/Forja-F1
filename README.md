# Forja F1 2026 — Фаза 1+

Неофициальный фан-симулятор / трибьют Formula 1 сезона 2026.  
**Не связан** с Formula 1®, FIA, Liberty Media или командами. Лицензий нет — только стилизация.

Сделано для Melgy.

## Запуск

```bash
cd /workspace/f1-2026
npm install
npm run dev
```

Откройте URL из терминала (обычно `http://127.0.0.1:5173`).

Сборка:

```bash
npm run build
npm run preview   # опционально
```

Только веб (Vite + Three.js). Нативных сборок Win/mac нет.

## Пит-лейн и обязательный пит-стоп

### Как работает пит-лейн (все трассы)
- Гоночная лента / центрлайн / Tecpro **не перекраиваются** — пит добавлен как **отдельный spur** снаружи правых барьеров у S/F.
- Проёмы Tecpro только на **въезде** (до финиша) и **выезде** (после старта); между ними стена между трассой и питом сохраняется.
- Spur (~9.5 м ширины) в форме **дуги**: въезд плавно отходит от гоночной линии, середина (боксы) заметно дальше от асфальта гонки, выезд дугой возвращается к трассе — не «приклеен» параллельно.
- Въезд заметнее: длинный жёлто-белый пунктир на гоночном асфальте, шевроны, яркие бордюры у рта, таблички «ПИТ».
- Въезд → вдоль пит-полосы → стоп у боксов (≤ ~25 км/ч) → мини-игра (1/2/3 / Пробел) → выезд обратно.
- Детекция / apron — зона `PitLane` (совпадает с дугой + midBulge). Time Trial: пит UI не открывается.

### Обязательный пит (Быстрая гонка / Обучение)
- Нужно **хотя бы один** полностью завершённый пит (мини-игра: шины + крыло + топливо) до конца круга `ceil(totalLaps/2)`.
- Пример на 3 круга: дедлайн = круг **2** (пит на кругах 1–2). Пропуск → **ДИСКВАЛИФИКАЦИЯ**, экран результатов с причиной.
- HUD (RU): «Обязательный пит до круга X»; на последнем круге окна — предупреждение.
- Time Trial: правило не действует.

## FPS-стратегия (цель ~60 на среднем ноутбуке)

Профили в **Настройки → Графика** (сохраняются в `localStorage`, схема v2):

| Профиль | pixelRatio | Тени | Пост | Декор | AI Hz | Цель |
|---------|------------|------|------|-------|-------|------|
| **Низкое** | ≤1 | OFF | OFF | мало | 24 | слабый iGPU |
| **Среднее** (default) | ≤1 | мягкие тени машин (1024) | OFF | средний | 30 | **~60 FPS** |
| **Высокое** | ≤1.25 | тени декора + машин | bloom+виньетка | больше | 40 | качество |
| **Ультра** | ≤1.5 | 2048 soft | сильнее пост | максимум | 48 | AAA-lite |

### Как проверить FPS
1. Меню → **Настройки** → **Счётчик FPS → Вкл (HUD)** → Сохранить
2. Запустить быструю гонку
3. В левом верхнем углу HUD: `NN FPS` (обновление ~2 раза/с)
4. Если &lt;50 на Среднем → переключить на **Низкое**

### Бюджет FPS
- Medium: тени только от машин (декор не кастует) — без EffectComposer
- High/Ultra: UnrealBloom + vignette; reflective harbor water
- `InstancedMesh` для зданий / деревьев / фонарей
- Декор **только** с внешней стороны асфальта+барьеров+margin
- Lambert/Basic на Low/Medium; Physical paint на машинах
- Разметка трассы — один merged BufferGeometry
- Frustum culling ON; атмосферный fog

## Что улучшено в этой итерации

### Руль острее (удержание L/R)
`steerRamp` 6 (мягче к комфорту 5.5–6.5), `PLAYER_STEER_YAW_SMOOTH` keep/apply 0.50/0.50, `maxSteer` 0.68 — больше keep на yaw. QR = TT. A/← влево, D/→ вправо.

### Теххарактеристики болида
В экране старта (гараж/ливрея) — блок «Технические характеристики» (RU): масса, мощность, ERS кВт, макс. скорость, Cl/Cd, база, шины. Цифры из `PLAYER_VEHICLE_SPEC`.

### Интерлагос + Сузука без z-fight
Переразметка лент: Interlagos climb на западе (не над Senna S); Suzuka — Dunlop ΔY≥6.8 + return-flyover над 130R (ΔY≥6.5); спуск flyover заканчивается на южном stub до стыка с S/F — **0 копланарных** overlap (диагностика). Terrain sink глубже; кербы/Tecpro/плечи/трава пропускают копланарные чужие ленты.

### Стены = Tecpro (после туннеля и везде)
Физика жёстко клампит на `TRACK_BARRIER_OUT` (1.2 м от края асфальта) — совпадает с визуальными Tecpro. Больше нельзя «пролететь» сквозь барьер на выходе из туннеля Монако.

### ERS = 200 кВт
Точно 200 кВт буста; drain ~0.125/с ≈ 8 с полного бара.

### Две новые трассы
**Сузука** (figure-8 с оверпассом) и **Интерлагос** (Senna S + холмы). Выбор «Трасса» в меню старта (русские подписи). Монако не сломан (harbor/tunnel только у `id=monaco`).


### Фотореалистичный графический пасс (Monaco)
Сильнее midday sun + hemisphere/bounce fill, ACES + SRGB, мягкие тени на Medium+, clearcoat-ливреи (MeshPhysical), темнее асфальт с roughness-картой, Tecpro/спонсоры, reflective гавань (High+), лёгкий bloom/виньетка (High/Ultra). Тиры переименованы: Ультра = максимум (старое «ультра-низкое» мигрирует в Низкое).

### Нет сине-белых кубов на асфальте
Убраны клумбы-боксы и синие спонсорские панели; Tecpro — только красно-белые soft-wall’ы (+ верхняя кромка). Декор дальше от ленты с доп. clearance.
Яхты в гавани после туннеля сдвинуты в воду с проверкой ribbon clearance (больше никаких бело-синих боксов на асфальте Nouvelle Chicane).

### Одинаковая физика игрока: Quick Race = Time Trial
`PLAYER_VEHICLE_SPEC` + `INPUT_SMOOTHING` / `PLAYER_STEER_YAW_SMOOTH` — одна масса, мощность, ramp газа/руля в обоих режимах. Столкновения с AI не режут `damageMul`/maxPower игрока.

### Машины F1 2026 (procedural, не blocky)
Общий builder для игрока и AI (`CarMesh.ts`), shared BufferGeometry между инстансами:
- Sculpted lathe nose / sidepods / engine cover; capsule tub (не кубы)
- Bargeboards, floor strakes, undercut scoop + louvres, side winglets
- Halo, mirrors, helmet; 4-element FW + RW (DRS flap, beam, endplates) с лёгким anhedral
- Diffuser + suspension + детальные колёса; clearcoat MeshPhysical paint
- Number panels + accent stripes; ~5 машин на Medium без просадки FPS

### Графика Medium ~60 FPS
Асфальт 512² с износом/маслом, env cubemap 128² с солнцем, ярче дневной свет, anisotropy 4, чуть больше scenery при том же pixelRatio 1 / без теней.

### Античит кругов
Круг засчитывается только при **прямом** пересечении S/F и после ≥**80%** длины трассы с прошлого круга. Обратная езда / дрожание у шва не удваивает круги; после финишной черты нужно выехать из зоны S/F (~40 м), чтобы снова «вооружить» детектор.

### Noghes / S/F без пересечений текстур
Сглаженный Noghes, terrain утоплен под асфальт, кербы/плечи/soft-edge **пропускают** ~20 м у шва петли — путь чистый, без z-fight лент.

### Барьеры Tecpro + спонсорские борды
Красно-белые soft-wall’ы (Tecpro-like) + брендированные панели **FORJA / TEC / HYDRO / NEXUS / …** (вымышленные имена, InstancedMesh).

### Живее пейзаж (с тирами качества)
Более выразительный рельеф (утёсы у тоннеля, террасы Casino, берег гавани), лиственные кусты, плотнее клумбы/скалы/здания; High/Ultra denser — без ломки цели ~60 FPS на **Среднем**.

### Позиция в гонке (lap + s)
Порядок: **круг**, затем **distanceAlong (s)** вдоль центрлайна — `progress = (lap - 1) * length + s`. HUD и экран результатов используют одну функцию. На финише место фиксируется по `finishTimeMs` (кто раньше закончил), чтобы пересечение S/F не ставило игрока выше уже финишировавших AI. Self-check: позади 2 AI на том же круге → позиция **3**.

### Скала у входа в тоннель
Крупная читаемая скальная формация у портала тоннеля Монако (вне асфальта), тиры качества режут число чанков.

### Шире трасса Монако
Полуширина / `width` увеличены ×**4.0** (играбельная уличная ширина ~28–48 м, ~2× прежних ×2.05). Барьеры, кербы, стены и физическая проекция (`projectOnTrack` / halfW) берут ту же ширину — без рассинхрона.

### Нет серых плит на асфальте
Причал/apron гавани больше не режет Tabac (перенесены внутрь петли + `boxClearsRibbon`). Гравий и лодки только вне ленты. S/F — тонкий декал, не толстый бокс.

### Оверпассы без телепорта
`projectOnTrack(..., preferredS, preferredY)` штрафует чужую палубу и отказывает в прыжке >~2 м (кроме рампы). Под Swimming Pool / Beau Rivage машина остаётся на нижнем ярусе.

### Руль и сглаживание
WASD и стрелки: A/← влево, D/→ вправо. Аркадный отклик: быстрый lerp руля/газа, yaw-lerp чувствительнее, но без дёрганья на широкой ленте.

### Нет столбов посреди асфальта
Опоры эстакад/оверпассов ставятся **только вне** всех лент трассы (асфальт + margin). На X-пересечениях (Swimming Pool / Beau Rivage) боковой offset больше не падает на нижний центрлайн — столб либо выталкивается, либо пропускается. Нижние «балки»-deck по центрлайну убраны.

### Шов старт/финиш / Noghes
Anthony Noghes → S/F: непрерывный правый поворот без складки ленты (убран backtrack 70→50/−55). Касательная на стыке ≈ +Z. Закрытие петли чистит дубликаты; полоса S/F приподнята + polygonOffset.

### Ускорение
Меньшая масса (~620) и выше пиковая мощность (~1130 кВт) — быстрее разгон; тормоза ~+14%.

### Столкновения машин
Круговые hitbox’ы игрок↔AI и AI↔AI: разделение, замедление/отскок при контакте, лёгкий урон — без ghosting.


### Здания не на трассе
Размещение вдоль **нормалей к краю** ленты. Любой проп, чья AABB пересекает асфальт+барьер+margin, **выталкивается** наружу или отбрасывается. Никакого random около центрлайна.

### ~60 FPS
См. таблицу профилей выше. Default = Medium без теней, pixelRatio 1.

- Простая вода, инстанс-здания с окнами, дешёвые night-emissive на фонарях
- Убраны лишние лодки / point lights / клиппящий декор у барьеров
